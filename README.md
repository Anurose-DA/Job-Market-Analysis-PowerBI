# Job Market Analysis using Excel & Power BI

## Project Overview
This project analyzes job market data using Microsoft Excel and Power BI to identify salary trends, company information, industries, and other key insights that support business decision-making.

## Tools Used
- Microsoft Excel
- Power BI

## Key Insights
- Information Technology sector has the highest revenue.
- Biotechnology & Pharmaceutical is the highest-paying industry.
- Salary ranges from 31K to 331K.
